# llano-river-eDNA
Code related to project involving plant eDNA metabarcoding of water samples in North Llano River and South Llano River. All scripts were generated with at least some assistance from Google Gemini models. UPDATE: the only script that will run properly is the allAnalyses script. This was the version used to generate all figures and run all analyses in the final manuscript that was accepted for publication on 10-01-26.
